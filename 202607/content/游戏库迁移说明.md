# 游戏库迁移说明

## 当前结果

- 旧版来源：`data/games.json`，框架版本 v5。
- 旧版记录：35 条。
- 正式游戏：34 款。
- 设计样例：1 条（骰子德州·提案）。
- 迁移阶段与新版已有产品合并：3 款。
- 迁移阶段新增旧版产品：31 款。
- 迁移完成时保留新版产品：1 款，正式产品共 35 款。
- “幸运城市”已与旧库中的《幸运市长》合并，并采用 Steam 官方名称。
- 后续补充分类样本后，当前正式游戏总数：46 款（2026-08-14 数据校验结果）。

## 迁移原则

1. 新版运行时只读取 `202607/data`，不依赖旧版数据文件。
2. 旧版原文保存在 `legacy-v5-snapshot.json`，避免迁移过程中丢失信息。
3. 旧版字段到新版八字段的映射标记为 `mechanical_import_unconfirmed`。
4. 迁移程序不会根据旧版标签自动确认机制母型、品类原型或游戏变体。
5. 幸运房东保留新版已经确认的原型关系，不生成重复产品。

## 执行命令

只检查，不写文件：

```bash
node 202607/scripts/migrate-legacy-games.mjs --check
```

执行迁移：

```bash
node 202607/scripts/migrate-legacy-games.mjs
```

迁移完成后校验：

```bash
node 202607/scripts/validate-data.mjs
```

## 输出文件

- `products.json`：正式产品目录。
- `product-formula-observations.json`：旧版字段到新版体验公式的观察映射。
- `legacy-v5-snapshot.json`：旧版完整数据快照。
- `design-samples.json`：不计入正式游戏数量的设计样例。
- `migration-report.json`：迁移数量、去重与缺失资料报告。
