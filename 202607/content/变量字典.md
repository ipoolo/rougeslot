# 双峰多巴胺体验模型 · 变量字典

> 对应公式版本：`202607-draft.3`
> 说明：`稳定`表示已由最新版公式确认；`工作定义`表示可以用于继续讨论但尚未最终冻结；`待确认`表示只能作为候选。

---

## 1. 总表

| key | 中文名 | 类型 | 状态 | 公式位置 |
|---|---|---|---|---|
| `P_t` / `P(t)` | 目标压力域 | 外层边界条件 | 工作定义 | 包裹完整 `[Spin]ₙ → BD` 循环 |
| `Pool_Symbol` | 符号池 | 输入集合 | 稳定 | `Random@Pool_Symbol` |
| `Random` | 随机抽取 | 操作 | 稳定 | Spin 第一步 |
| `SingleSpin_Symbol` | 单次 Spin 抽取结果 | 中间结果 | 稳定 | Random 输出、Put 输入 |
| `Put` | 放置／安置 | 操作 | 稳定 | Spin 第二步 |
| `Show_TP` | 表演拓扑／承载拓扑 | 空间类型 | 稳定 | Put 与 Combo 的共同承载域 |
| `Show_State` | 本次表演状态 | 中间结果 | 工作定义 | Put 输出、Combo 输入 |
| `C1` | 符号协同 | 规则集 | 稳定 | Combo 参数 |
| `C2` | 协同结果演绎 | 规则集 | 稳定 | Combo 中位于 C1 之后的可选层 |
| `Combo` | 协同判定与结算 | 操作 | 稳定 | Spin 第三步 |
| `Spin_Result` | 单次 Spin 结果 | 输出结果 | 工作定义 | Combo 输出 |
| `N` | BD 前连续 Spin 数量 | 周期参数 | 稳定 | `[Spin]ₙ` |
| `BD` | 构筑决策 | 操作 | 稳定原则，下层约束具体范围 | N 次 Spin 之后 |

# 2. P(t)

## 一句话定义

> 以目标、期限、当前差距与失败代价包裹完整 Spin → BD 循环的可选外层边界条件。

## 输入／输出角色

- 输入当前目标、剩余期限、累计进度和失败代价。
- 读取 `Spin_Result` 是否缩小了目标差距。
- 影响玩家在 BD 中的构筑方向和下一周期的紧迫度。

## 需要描述的内容

- 目标或达标阈值。
- 目标检查时点与剩余期限。
- 当前进度与目标之间的差距。
- 未达标后果。
- 压力如何随阶段增长、收紧或改变。

## 边界

- `P(t)` 不是 Random、Put、Combo 或 BD 旁边的第五个操作。
- `P(t)` 不直接参与符号抽取、放置或协同计算。
- `P(t)` 的检查周期独立于 N。
- 没有硬性失败压力的游戏，可以使用软目标或令 `P(t)` 不适用。

## 关系

```text
P(t) ⟦ [ Random@Pool_Symbol → Put@Show_TP → Combo(C₁→C₂?)@Show_TP ]ₙ → BD ⟧
```

以《幸运房东》为例，房租目标属于 `P(t)`；每次 Spin 后选择新符号属于 `N = 1 → BD`。

## 状态

`工作定义`

---

# 3. Pool_Symbol

## 一句话定义

> Random 在一次 Spin 中唯一直接读取的候选符号池。

## 输入／输出角色

- 作为 Random 的输入。
- 本身不是一次 Spin 的结果。
- 原则上可以被 BD 改变，具体方式由下层机制规定。

## 需要描述的内容

- 池中有哪些符号身份和类型。
- 每种符号的数量或抽取权重。
- 是否允许重复。
- 当前哪些符号可被 Random 读取。
- BD 能增加、删除、替换或调整哪些内容。

## 边界

Pool_Symbol 负责“可能抽到什么”，不负责：

- 本次实际抽到了什么。
- 抽到后如何放置。
- 元素如何协同。
- 最终如何结算。

## 关系

```text
Pool_Symbol ──Random──> SingleSpin_Symbol
```

## 状态

`稳定`

---

# 4. Random

## 一句话定义

> 从 Pool_Symbol 中为一次 Spin 随机选择出 SingleSpin_Symbol 的过程。

## 输入

```text
Pool_Symbol
```

## 输出

```text
SingleSpin_Symbol
```

## 可描述参数

- 抽取数量。
- 概率权重。
- 是否放回。
- 重复是否允许。
- 随机种子或伪随机规则。
- 抽取过程的时间与呈现。

## 边界

Random 不产生由 Put 决定的位置关系，也不执行 Combo。

## 状态

`稳定`

---

# 5. SingleSpin_Symbol

## 一句话定义

> 一次 Random 完成后、Put 开始前，本次 Spin 已经选出的符号结果。

## 来源

```text
Random(Pool_Symbol)
```

## 去向

```text
Put(SingleSpin_Symbol) @ Show_TP
```

## 正式边界

- 已经确定“抽到了什么”。
- 不强制定义为无序多重集。
- 可以是单个符号、一组无序符号，或由具体机制定义的其他结构。
- 是否有序、是否允许重复，由机制母型和下层原型规定。
- 它描述 Random 输出了什么；Show_TP 描述结果最终在哪种结构中被 Put 与 Combo 使用。

## 状态

`稳定`

---

# 6. Put

## 一句话定义

> 把 SingleSpin_Symbol 写入或安置到 Show_TP，形成 Show_State 的过程。

## 输入

- `SingleSpin_Symbol`
- `Show_TP`
- Put 的控制规则

## 输出

```text
Show_State
```

## 正式类型

| key | 中文名 | 正式解释 | 状态 |
|---|---|---|---|
| `auto` | 自动 | 系统或装置完成全部 Put，玩家不直接干预 | 已确认 |
| `semi_manual` | 微手动 | 系统完成主要过程，玩家只能调整局部步骤、有限选项或少量位置 | 已确认 |
| `full_manual` | 全手动 | 玩家主动决定主要的选择、放置、映射或排列结果 | 已确认 |

## 边界

Put 决定“结果如何进入舞台”，不决定：

- 从 Pool_Symbol 中抽什么。
- 满足什么 Combo。
- 最终数值如何结算。

## 状态

概念与一级枚举均为 `稳定`

---

# 7. Show_TP

## 一句话定义

> Put 写入结果、Combo 读取并判定结果时共同使用的空间结构类型。

## 作用

- 规定 Show_State 可以具有哪些关系。
- 决定“相邻、先后、首尾相接、距离、碰撞”等关系是否存在。
- 为 Put 提供目标空间。
- 为 Combo 提供判定空间。

## 与 Show_State 的区别

```text
Show_TP    = 类型
Show_State = 本次实例
```

## 正式枚举

| key | 中文名 | 核心结构 | 典型关系 |
|---|---|---|---|
| `0D_multiset` | 0D 多重集 | 无位置、无顺序，只保留类型与数量 | 数量、重复、类型组合 |
| `1D_sequence` | 1D 序列 | 元素具有前后次序，两端不相接 | 先后、连续段、前后影响 |
| `1D_ring` | 1D 圆环 | 一维次序首尾相接 | 环上邻接、循环距离、落点 |
| `2D_grid` | 2D 离散网格 | 元素位于离散行列坐标 | 邻接、对角、连线、区域 |
| `2D_physical` | 2D 连续物理空间 | 元素具有连续坐标和物理过程 | 路径、距离、碰撞、反弹 |

这五类已从旧版候选重新确认为新版正式一级枚举。

## 状态

概念与一级枚举均为 `稳定`

---

# 8. Show_State

## 一句话定义

> 某一次 Spin 中，SingleSpin_Symbol 经 Put 写入 Show_TP 后形成的具体状态。

## 输入来源

```text
Put(SingleSpin_Symbol, Show_TP)
```

## 输出去向

```text
Combo(Show_State, C1, C2)
```

## 包含的信息

根据 Show_TP 的不同，Show_State 可以包含：

- 元素类型。
- 元素数量。
- 顺序。
- 离散坐标。
- 邻接关系。
- 连续坐标。
- 路径或碰撞状态。

## 状态

`工作定义`

---

# 9. C1

## 正式名称

```text
符号协同
```

## 一句话定义

> 来源于先验装置及玩家先验知识，在 Show_TP / Show_State 上决定符号之间如何协同的规则集。

## 认知边界

- 主要来自玩家对先验装置或现实原型已有的理解。
- 玩家几乎不需要重新学习。
- 或者只需要学习少量相对于既有先验的变化点。

## 输入

- `Show_State`
- `Show_TP`
- C1 规则定义

## 输出

基础协同判定结果，交给 Combo 继续结算。

## 待案例校准

- 符号协同的具体子类型。
- 如何判断某条规则仍属于少量变化点。

## 状态

`稳定`

---

# 10. C2

## 正式名称

```text
协同结果演绎
页面简称：结果演绎
```

## 一句话定义

> 作用于 C1 基础结果之上的可选二次规则层，负责对协同结果进行修饰、转换或映射，形成最终的 Spin_Result。

## 输入

- C1 产生的基础协同结果。
- Show_State。
- 当前演绎规则与上下文。

## 输出

经过修饰或转译后的 Combo 结算结果。

## 可以产生的影响

- 修饰型演绎：增加倍率、条件、例外、连锁，或改变基础结果的计算方式与性质。
- 转译型演绎：将基础结果映射为伤害、治疗、防御、技能触发、资源、状态或其他机制结果。
- C2 可以不启用；此时 C1 基础结果直接进入 Spin_Result。
- 只改变动画、音效或界面表现，不属于 C2。

## 与 C1 的区别

```text
C1 识别先验装置中容易理解的符号协同，并产生基础结果
C2 在基础结果之后，选择性地完成修饰或结果转译
```

## 待案例校准

- 修饰型演绎与转译型演绎的细分类型及边界案例。
- 跨越多次 Spin 的修饰如何表达。

## 状态

`稳定`

---

# 11. Combo

## 一句话定义

> 在 Show_TP / Show_State 上依据 C1、C2 完成规则判定和结果结算的过程。

## 输入

- `Show_TP`
- `Show_State`
- `C1`
- `C2`

## 输出

```text
Spin_Result
```

## 边界

Combo 不负责：

- 从 Pool_Symbol 随机抽取。
- 把 SingleSpin_Symbol 放入 Show_TP。
- 多次 Spin 之间的玩家构筑调整。

## 体验作用

```text
第二峰
```

## 状态

`稳定`

---

# 12. Spin_Result

## 一句话定义

> 单次 Spin 经 Combo 完成判定和结算后产生的可观察结果。

## 可能形式

- 数值。
- 资源变化。
- 战斗结果。
- 状态变化。
- 多项结果的组合。

具体形式由机制母型和品类原型规定。

## 后续用途

- 作为本次 Spin 的反馈。
- 进入 N 次结果的累计或比较。
- 为后续 BD 提供信息。

## 状态

`工作定义`

---

# 13. N

## 一句话定义

> 当下层启用 BD 时，触发一次 BD 之前连续发生的 Spin 数量。

## 公式位置

```text
[ Random → Put → Combo ]ₙ → BD
```

## 正式规则

- 当 BD 启用时，`N ≥ 1`。
- 多次 Spin 后触发一次 BD。
- N 的具体值由游戏规则动态决定。
- 每次 Spin 后都触发 BD 时，表示为 `N = 1`。
- N 不表示更长的目标压力检查周期；该周期属于 `P(t)`。
- 机制母型可以同时禁用 `N` 与 `BD`；此时 `N` 不适用。
- 品类原型可以在母型先验上重新启用 `N → BD`。

## 状态

`稳定`

---

# 14. BD

## 当前工作名称

```text
Builder Decision / 构筑决策
```

## 一句话定义

> 玩家基于一个周期内的结果，对后续 Spin 所使用的构筑参数进行调整的过程。

## 输入

- 一个或多个 `Spin_Result`。
- 当前构筑状态。
- 当前可选择的调整项。

## 输出

后续循环的参数变化。

## 可能影响

- P(t) 中规则允许由玩家改变的目标、期限、容错或风险参数。
- Pool_Symbol 的内容。
- Random 的概率或数量参数。
- Put 的控制方式或可选操作。
- Show_TP 的参数，或在具体机制允许时改变其类型。
- C1/C2 规则。
- N 或周期节奏。

原则上，BD 可以修改公式中的大部分可配置变量；某个具体游戏允许修改哪些、禁止修改哪些，由机制母型、品类原型和品类变体逐级约束。

BD 不改变体验模型的基本流程身份：

```text
Random → Put → Combo → BD
```

## 待案例校准

- 各机制母型允许 BD 修改的具体字段。
- BD 如何回应 P(t)，以及哪些游戏允许 BD 直接改变目标压力参数。

## 状态

原则 `稳定`，具体可修改范围由下层约束

# 15. 已确认的一级分类

## Put

```text
自动
微手动
全手动
```

## Show_TP

```text
0D 多重集
1D 序列
1D 圆环
2D 离散网格
2D 连续物理空间
```

## Combo

```text
C1：符号协同
C2：协同结果演绎（简称：结果演绎）
```

具体子类型在后续案例拆解中校准。
