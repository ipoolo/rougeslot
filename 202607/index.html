体验目标 持续爱干

玩家在多次短循环后，仍愿意主动开始下一次操作、观察结果并调整构筑。

一次 Spin 的双峰体验，与多次 Spin 后的构筑循环 主干已确认
[ 多巴胺峰值 ① 结果揭晓 · 控制感 Random@ Pool_Symbol → Put@ Show_TP → 多巴胺峰值 ② 协同识别 · 结算 Combo(C₁ → C₂?) @ Show_TP ]ₙ → 长期循环 不是第三峰值 BD构筑决策
Pool_Symbol Random SingleSpin_Symbol Put @ Show_TP Show_State Combo(C₁ → C₂?) @ Show_TP Spin_Result 累计 × N BD 修改参数 下一周期
体验映射 双峰发生在一次 Spin 内

第一峰来自 Random + Put 的结果揭晓与控制感；第二峰来自 Combo 的协同识别与结算。

@ 作用域 随机域与承载域分开

Random 只直接读取 Pool_Symbol；Put 与 Combo 则共同使用同一个 Show_TP。

C₁ / C₂ 基础协同与结果演绎

C₁ 产生低学习成本的基础协同结果；可选的 C₂ 再对结果进行修饰，或转译为战斗、资源与状态等结果系统。

N → BD 短循环进入长期构筑

当下层启用 BD 时，N ≥ 1 且动态决定；未启用构筑的机制可以令 N 与 BD 不适用。

本模型本质上是对这类游戏的抽象假设。

公式是整站的共同底座。 机制母型、品类原型与品类变体，都必须说明自己约束或改变了哪个公式字段。

01 · 体验模型的抽象架构

三个体验阶段：
揭晓 → 结算 → 构筑

公式保留 Random、Put、Combo 与可选的 BD 接口；当下层启用构筑循环时， 玩家体验可以归纳为三个阶段。

EXPERIENCE TIMELINE

一次 Spin 的双峰，与 N 次后的构筑节点

一次 Spin · 短周期（连续重复 × N） 周期边界 · 长期构筑
Spin 开始 → × N → ↺ 下一周期
完整循环 揭晓与结算构成单次 Spin 的双峰，连续 N 次后进入构筑。

构筑通过 BD 修改可配置参数，再把玩家送回下一周期的 Random。

阶段 01 多巴胺第一峰

结果揭晓与呈现

Random + Put

玩家等待随机结果出现，并看到结果进入 Show_TP。 如果 Put 允许玩家参与，还会产生放置或选择的控制感。

玩家此刻关心：这次抽到了什么，结果怎样落下？
→
阶段 02 多巴胺第二峰

协同识别与结算

Combo(C₁ → C₂?)

玩家先识别 C₁ 符号协同，再观察可选的 C₂ 如何修饰基础结果， 或将其转译为数值、战斗、资源与状态结果。

玩家此刻关心：组合触发了什么，最终得到多少（数值），或呈现了怎样的开奖过程（表演）？
→
阶段 03 长期构筑循环

构筑调整与再次期待

[Spin]ₙ → BD → 下一周期

当下层启用 BD 时，完成 N 次 Spin 后，玩家根据周期结果调整符号池、 随机参数、Put、协同规则或周期节奏，再进入下一轮。

玩家此刻关心：下一轮要改什么，能不能变得更强？
