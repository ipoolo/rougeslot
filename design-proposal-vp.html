① 概念定位 · 跟爆款的差异化

差异化卖点（3 条）：
  1. 多线杠杆决策——一次 hold 决策放大 N 倍结果。决策密度 × 心理张力两者皆比 Balatro 高（决策更频繁，每次决策影响更大）
  2. 赌场原教旨主义——video poker 是真实存在 50+ 年的赌博机经典玩法，玩家有"我在玩真实赌徒玩的游戏"的代入感
  3. 概率养成的"赌徒哲学"——你不能换牌，只能改"运势" → 跟"还债 + 恐怖叙事"主题完美贴合

② 复杂度消除 · 把"1D 顺子 + 独立多线"统一为"2D 网格 + 0D 牌型字典"

关键洞察（来自用户对话精炼）
朴素 Video Poker 多线复杂度根源 = 「1D 顺子」 + 「独立多线 5 张完整牌型」 两条同时叠加
解决思路：两个维度同时简化，让每条 line 退回 0D 多重集，让多线统一为 2D 网格。
维度 ① 把"1D 序列"消除，变回"0D 多重集"
顺子判定让系统自动按点数内禀排序——玩家永远不需要管顺序（跟 Balatro 同思路）。
  • 玩家 hold 决策时，5 张牌按花色或点数自动排显示，不可拖动
  • 系统判定顺子时按点数排序检查
  • 顺子降级为 type_dict 的一个条目——「顺子也是一种类型」，跟"对子"、"同花"平级
  • → show_topology 单线内回到 0D_multiset，put_form 维持 manual_set
维度 ② 把"独立多线 5 张牌"统一成"网格 line_complete"
借用 Cloverpit 的网格思路——5 × M 网格统一视觉舞台：
   朴素 video poker 多线（视觉碎片化）：
      [♠A ♠K ♠Q ♠J ♠10]  ← line 1
      [♥A ♥K ♥Q ♣J ♦10]  ← line 2
      [♣A ♠K ♠2 ♣5 ♦7 ]  ← line 3   N 条独立 5 张牌区 → 复杂度爆炸

   改造后 video poker 网格（Cloverpit 风格）：
          col 1  col 2  col 3  col 4  col 5
   row 1:  ♠A    ♠K    ♠Q    ♠J    ♠10      ← row 1 牌型评分
   row 2:  ♠A    ♠K    ♠Q    ♣J    ♦10      ← row 2 牌型评分
   row 3:  ♠A    ♠K    ♠2    ♣5    ♦7       ← row 3 牌型评分
   row 4:  ♠A    ♠K    ♥Q    ♠4    ♣9       ← row 4 牌型评分
   row 5:  ♠A    ♠K    ♦3    ♠7    ♥10      ← row 5 牌型评分

   玩家 hold col 1, col 2  → 该列全列锁定 ♠A / ♠K
   重抽 col 3-5            → 每行独立重抽这 3 列

   ★ 所有牌在一张 5×M 网格里，统一视觉
结果：show_topology = 2D_grid（跟 Cloverpit 完全同构）；combo_predicate 复用 line_complete + type_dict + cascade。

④ 网格 UI 草图（决策 / 表演 / 结算 三阶段）

UI 信息密度通过分阶段呈现控制：决策阶段只见主行 5 张；表演阶段网格波浪展开；结算阶段逐行高亮 + charms 顺序触发。

阶段 1 · 决策 · 玩家只看主行 5 张做 hold 决策
玩家心智负担：5 张主行牌 + hold 决策。决策聚焦，UI 不拥挤。
阶段 2 · 表演 · 拉杆后多线波浪式展开（1-2s 戏剧化）
5 列 × 5 行网格统一视觉。锁定列波浪式展开（row 1 → row 5），可见列同色、对角线、单行牌型 3 种 line 同时触发。
阶段 3 · 结算 · 逐行高亮 + charms 顺序触发（滚雪球）
285 → 144,000 = 505 倍放大。5 个 charms 的乘性链是核心爆发器。每个 charm 亮起 + 数字翻飞，复刻 Cloverpit 滚雪球节奏。

⑤ 150 Charms 池详细设计（5 类 × 30 个）

题材：高利贷地下赌场 / 1980s Vegas Noir。每个 charm 是赌徒护身符 / 黑帮赏赐 / 死亡纪念品。
稀有度梯度：普 60% 罕 25% 史 12% 传 3%。

⑥ 数学模型 · 单 spin 产出公式

Output_per_spin = // 第一层：每行牌型评分（加法） Σ_{row=1..M} HandRank(row) × payTable[handType] // 第二层：网格 line_complete 加成（加法） + Σ_{line ∈ {列, 对角, 多行同型}} lineBonus(line) // 第三层：charms 乘性链（乘法） × ∏_{i=1..n_charm} (mᵢ × position_bonus_i) // 平衡约束 Target_per_round = T₀ × rround // r = 2.0（指数递增） Player_capacity = ∏ mᵢ ≈ Target // 平衡设计 // 参数建议 M (line 数) = 5 → 10 → 25 // 跨局解锁 n_charm 槽 = 5 (起手) → 8 (后期解锁) mᵢ 范围 = [1.5, 10] (普到传) n_pool = 150 charms

⑦ 主要风险 + 对策

风险 1跟 Balatro 的混淆（最大风险）
玩家第一反应可能是"这不就是 Balatro 吗"。
对策：宣传素材突出 hold 机制 + 多线视觉——展示 25 行同步翻牌的视觉爆炸 → 一句话差异化「Balatro 让你选 5 张出，本作让你选 5 张留——但你的留会被复制 25 倍」。
风险 2教学门槛（VP 在东亚陌生）
中国玩家不熟 video poker 规则。
对策：前 3 关教学化（1 line → 3 line → 5 line），每线扩展时新规则提示。
风险 3赌博争议
多线 VP 是真实赌博机机制。
对策：参考 Cloverpit「真实毁灭」叙事——把游戏定位为"反赌博的赌博恐怖游戏"，主题强调"赢的不是钱，是脱困"。
风险 4多线 UI 拥挤
10 line × 5 牌 = 50 张牌同屏。
对策（已实施）：本提案改造为5×M 网格 + 分阶段呈现（决策 5 张 / 表演波浪 / 结算逐行）。复杂度从"独立 N 个 5 张牌区"降到"统一网格"。详见 §②、§④。
风险 5数学平衡难
M 条 line × 150+ charms × 修饰器叠乘 = 公式复杂度爆炸。
对策：参考 Balatro 团队「数值表 + 单元测试 + Mod 验证」方法论，需要数学 / 概率背景的设计师。
