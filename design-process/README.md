# design-process · 占位

本目录留给系统的 v2 阶段：**设计 RPB 装置类游戏的流程模板 + 每个阶段的健壮性评估标准**。

当前是占位空间，v1 不实施。

## 计划内容（v2）

- `phase-1-mvp.md` —— Phase 1 原型阶段（4 元素：random + combo + 双层池 + 肉鸽底线）
- `phase-2-expand.md` —— Phase 2 扩充（pool 深度 / 压力曲线 / meta-progression）
- `health-criteria.md` —— 每阶段的健壮性评估标准（30 分钟留存 / 第二局重启率）
- `templates/` —— 可复制的设计文档模板（基础池 schema、主动池 schema、压力曲线 schema）

## 何时启动 v2

当 12 款游戏全部按 v1 框架分析完毕，并且至少跑过一轮跨维差察后启动。
