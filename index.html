设计模式 · RPB 装置类的底层抽象方式（v4）

本系统研究的"装置类 RPB"（Random-Pool Builder Roguelike）品类，可以压缩成一条公式 + 8 个核心概念 + 5 层递进推导。每款游戏（无论 slot / 弹球 / 骰子 / 卡牌）都能映射到这个统一模型上。
v4 升级：在 random 与 combo 之间识别出独立的 put 步骤——把 random 结果安置进 combo 评估空间。详见 设计完备模型总览 →

L4 · 完整产出公式（最终形态）

💰 产出 = ( 基础池 × random ) + ( 基础池 × 符号协同 ) × ( 主动池 × 规则修饰 )
📌 基础池在两个维度都起作用（提供 random 落位 + 提供符号协同的原材料）· 主动池只在最后一步修饰（乘法效应是双层池深度的来源）
⚡ v5 完备模型 · 公式中"基础池 × random → 符号协同"之间隐藏一步 put（把 random 结果安置进 combo 评估空间）；put 与 combo 共享同一个 show_topology（舞台拓扑）：
spin[ random → put（自动|手动 × set|place） → combo[ combo1 + combo2 ] ]_N → RPBD @ show_topology

8 个核心概念（公式中的角色 · v4 含 put）

🎁 基础池（pool_base）
每次 spin 装置上随机落位的元素池——slot 的符号 / 扑克的牌 / 弹珠台的 trinket / 骰子的骰面字典。关键：基础池在公式中出现两次（提供 random 内容 + 提供协同原材料），所以容量和稀有度梯度直接决定 random 和 combo1 的天花板。
范例：LBL 200+ 符号（普 60% / 非 25% / 稀 12% / 极稀 3%）· Balatro 52 张扑克 · 弹珠大亨 145+ Triggers
⚙ 主动池（pool_active）
玩家通过 RPBD 阶段构筑的修饰器池——LBL 的 100+ 道具 / Balatro 的 150+ Joker / 弹珠大亨的 55+ Boons。永远生效，仅在最后一步修饰 combo1 产出。乘法效应是双层池深度的来源——基础池决定能产什么，主动池决定产多少倍。
威力梯度：普温和 / 非中等 / 稀强力 / 传颠覆 · 通过商店购买，可卖出换金币
🎲 random（spin 抽出）
"装置怎么抽"——slot 转动 / 弹珠下落 / 骰子翻面 / 抽卡。这是第一峰多巴胺前段的来源（约 0.5-1.5s）。VR 触发（每次随机不可预测）+ 抽取戏剧化 + 视觉锁定（清晰可读）三要素决定 random 评分。random 输出本质是一个多重集（无序、不带位置；位置/顺序信息由 put 引入）。
v4 注：原来"落位"中的"放"语义被独立到 put 步骤；random 只负责"抽"。
🎯 put（v4 新增 · random→combo 映射）
把 random 抽出的多重集写入 show_topology（舞台拓扑）——put 与 combo 共享同一个舞台。装置自动落位（slot/物理）= auto_place；玩家手选子集（牌型）= manual_set；玩家放置/排序（棋盘/UNO 链）= manual_place。put 是第一峰多巴胺后段，也是 v3 漏掉的中间步骤。
v4 子项：put_form（4 枚举：auto_place 20 / manual_set 2 / manual_place 11 / auto_set 0 ‑ 结构性空类） · 详见 Put 维度详解 →
🔗 combo1 · 符号协同（基础池内元素互动）
put 后的元素在舞台拓扑上触发互动规则——3 樱桃 → 丰收 +5 / 2 ⚡ 邻接 → 闪电链 +3 / 同花顺 → ×100。基础池的固有规则，无条件触发。是 combo 的加法项。
v4 子项：show_topology（=舞台拓扑，5 选 1）+ combo_predicate（多选 8 种判定：阈值 / 类型字典 / 邻接 / 连线 / 链式约束 / 触发链 / 物理路径 / 连锁反应）
✨ combo2 · 修饰协同（主动池施加的全局修改器）
道具/Joker 对 combo1 结果做全局倍率/加成——水果 +50% / 每个 ⭐ ×2 / 玫瑰永不消失。是 combo 的乘法项。多道具叠乘的顺序和数量决定单局上限。
关键：combo2 不能改变基础池元素本身（那是 RPBD 的事），只能改变"怎么算"
🛒 RPBD · 玩家构筑决策
玩家在 spin 之间的构筑阶段——商店三选一买符号/道具 / 付费删 / 升级。RPBD 不在公式中但决定了下次 spin 的基础池和主动池参数，是双循环的关键节点。
决策周期：每 N spin 一次（LBL 5 spin/checkpoint）· 单局通常 8-24 次商店决策
🎯 checkpoint · 压力机制
周期性检查产出是否达标——每 N spin 一关 / 每 Blind 目标分 / boss 关倍率加强。压力来源，逼迫玩家在 RPBD 阶段做优化决策。5 个量化参数：M（关数）/ N（节奏）/ T₀（起始压力）/ r（增长率）/ m_boss（boss 加强）。
最强结构：目标分数族（房租 / Blind / 还债指数）—— LBL 10 / Balatro 9 / 四叶草深渊 9 都是这族
